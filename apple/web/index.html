What Gryvia does

You have one or more Apple Silicon Macs. Gryvia is a queue and a traffic controller for them: you hand it AI jobs (run a model, make embeddings, evaluate…), and it decides which Mac runs each one, when, without overloading memory. You watch and manage everything from this dashboard, the Mac app, or the command line.

Your first job in 3 minutes

  1. Start the server. make run-server (or it is already running on your Mac mini).
  2. Start a worker. make run-agent turns this Mac into a worker. For another Mac run make deploy MINI=hostname.
  3. Open this page and connect with the admin token from local/credentials.env, or press Try demo to explore with simulated data.
  4. Run a job. Press Run demo job on Workloads. It finishes in about 3 seconds.
  5. Check the result. Click Logs on the job. Press ⌘K any time to search commands.

Words you will see

Mac / node
One machine running the Gryvia agent. Shown in Mac fleet.
Workload / job
One task to run: a runtime (mlx, llama, coreml, demo), a model label, and arguments.
Reservation
Memory (GiB) a job sets aside on a Mac. It is bookkeeping for fairness, not a live GPU meter.
Queued → running → succeeded
Life of a job. Failed and cancelled are the other endings.
Tenant / quota
A team and its memory allowance, so one team cannot starve the others.
Drain
Stop sending new jobs to a Mac (for maintenance). Running jobs finish. Resume undoes it.
Priority
0–100. Higher goes first when jobs are waiting.

Command line cheat sheet

export GRYVIA_ADMIN_TOKEN=…          # from credentials.env
gryvia.py doctor                     # is everything healthy?
gryvia.py top                        # live view of Macs and jobs
gryvia.py submit job.json --wait     # run and wait for the result
gryvia.py jobs --state failed        # find problems
gryvia.py logs JOB_ID -f             # follow a job's output
gryvia.py drain MAC_ID               # stop new work on a Mac

Welcome to Gryvia: three steps to your first job

  1. Connect a Mac. A Mac joins by running the Gryvia agent. Locally: make run-agent. On another Mac: make deploy. It appears in Mac fleet within seconds.
  2. Run a job. No setup needed: sends a 3-second test workload to your fleet.
  3. Watch it finish. Open Workloads to see it go queued → running → succeeded, then click Logs.

How to read this

Each Apple Silicon Mac has one GPU made of many cores. The grid lights cores in proportion to the GPU's measured busy percentage.

Utilisation is the whole Mac's GPU load (it includes other apps). Job reservations are the memory each job set aside for admission; the marker shows what the GPU is actually using.
