# Security scope

This is a trusted-team engineering beta. Native runtime jobs are not sandboxed against hostile code. Static bearer tokens authenticate administrators, tenants and agents. Keep credentials private and use TLS for all remote control-plane access. See docs/OPERATIONS.md for process-survival, retention and deployment limitations.

Report vulnerabilities privately to Zyvor AI Labs through your established company support channel. Do not include secrets or complete private prompts in public issues.
